# Başka araçta kullan

Orkestra fikri Claude Code'a bağlı değil; dosya biçimi araca göre değişir.

| Dosya | Ne işe yarar |
|---|---|
| [`AGENTS.md`](AGENTS.md) | Codex ve AGENTS.md okuyan araçlar için orkestra kuralı |
| [`codex-agents/`](codex-agents) | `.codex/agents/` için gelistirici, denetci, arastirmaci örnekleri (`.toml`) |
| [`yapistir-prompt.md`](yapistir-prompt.md) | Herhangi bir yapay zekâya yapıştır; kendi modellerine eşleme tablosu çıkarır |

Not: `model` alanına kendi aracındaki model adını yaz; örneklerde yer tutucu var.
Alan adlarını ve yolları aracın güncel belgesinden doğrula.
